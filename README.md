# 🚀 Projeto360
---

## 💻 Sobre o Projeto

O **Projeto360** é uma aplicação desenvolvida com foco em uma arquitetura limpa e bem estruturada, utilizando o padrão de repositórios para separação de conceitos e facilidade de manutenção. 

O objetivo principal deste projeto é aprender como desenvolvedor uma API usando uma arquitera em camada, limpa e convencional.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e práticas:

* **.NET / C#** — Linguagem principal do ecossistema backend.
* **Arquitetura em Camadas** — Separação de responsabilidades (Repositório, Domínio, etc).
* **Git & GitHub** — Controle de versão e hospedagem do código.
* **Entity Framework Core / Dapper** — Para persistência e manipulação de dados.
* **SQL Server / Docker** — Banco de dados e containerização.
